# Contributing

Thanks for helping. Start with [START-HERE.md](START-HERE.md), then the guide for your role:

- [Reviewer guide](docs/guide-reviewer.md)
- [Runner guide](docs/guide-runner.md)
- [Developer guide](docs/guide-developer.md)

## The short version

1. Discuss first in GitHub Discussions or an issue.
2. Propose labels with the "Propose a label" issue form.
3. Submit compute results with the "Submit results" issue form.
4. Code and card changes go through pull requests using the template. `main` is protected.
5. Never commit corpus text, model files, outputs or keys.

Workflows and access levels are in [docs/team.md](docs/team.md).
